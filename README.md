# 🎮 Камінь, Ножиці, Папір

Класична гра **«Камінь, Ножиці, Папір»**, створена на Python з графічним інтерфейсом **Tkinter**.

Гравець обирає один із трьох варіантів за допомогою кнопки, після чого комп'ютер випадково робить свій вибір. Програма визначає результат раунду та веде рахунок.

## ✨ Можливості

* 🪨 Вибір **Каменя**
* ✂️ Вибір **Ножиць**
* 📄 Вибір **Паперу**
* 🤖 Випадковий вибір комп'ютера
* 🏆 Підрахунок перемог
* 💥 Підрахунок поразок
* 🤝 Підрахунок нічиїх
* 🎨 Сучасний темний дизайн
* ✨ Анімація перемоги
* 💥 Анімація поразки
* 🤝 Анімація нічиєї
* 🖱️ Вибір одним кліком

## 🛠️ Використані технології

* **Python 3**
* **Tkinter** — графічний інтерфейс
* **Random** — випадковий вибір комп'ютера

## 🎮 Як грати

1. Запустіть програму.
2. Натисніть кнопку **🪨 Камінь**, **✂️ Ножиці** або **📄 Папір**.
3. Комп'ютер зробить свій вибір.
4. Програма покаже результат.
5. Рахунок автоматично оновиться.

### 🏆 Правила

| Гравець   | Перемагає |
| --------- | --------- |
| 🪨 Камінь | ✂️ Ножиці |
| ✂️ Ножиці | 📄 Папір  |
| 📄 Папір  | 🪨 Камінь |
